# Fictional daily workflow

This example uses only `skills/li-read/assets/sample-read.json`, not the user's
account or private context. Run `python3 scripts/demo_brief.py` to reproduce the
selection in a disposable temporary directory. It does not modify project data.
The clock is fixed to 2026-10-02 at 12:00 UTC so the demo does not age unpredictably.

The supplied fictional own post says: “We added a dependency field to our review
checklist. We have not measured review time yet.” A peer asks whether review time
has been measured. Another relevant public discussion asks what a checklist should
record. A generic congratulatory comment is also present.

The helper selects two candidates, not a quota of five:

| Priority | Item | Reason | Suggested manual action |
| --- | --- | --- | --- |
| 1 | demo-c1 | User explicitly expects a reply to the measurement question | Review and reply |
| 2 | demo-n1 | User identified a relevant discussion and an actual contribution | Review and comment if useful |

The generic congratulation does not warrant a manufactured response. There is no
known relationship record, so no relationship or business opportunity is invented.
The supplied activity is fresh at the demonstration clock. Source labels are
USER-PROVIDED; priorities are INFERRED. Profile, feed, network, analytics and inbox
coverage are unavailable. This is Manual Mode, not live account access.

Python emits draft placeholders. Applying li-reply and the claim/quality gates to
the actual supplied evidence yields this illustrative reply:

> We haven't measured review time yet. The change so far is a dependency field in the checklist.

Applying li-comment can yield:

> We added a dependency field to ours. We haven't measured whether it changes review time yet.

These are example Codex-written drafts, not output generated by the ranking helper.
They use the supplied facts without claiming time savings, improved outcomes or
other measurements. In real use, Codex loads the user's voice before finalizing.

A human reviews and performs any reply/comment manually. Nothing is posted, liked,
connected or messaged. Only after actual publication is confirmed should its final
text, actual date and identifier enter publication history. Weekly review later
uses real supplied outcomes; it does not assume these drafts succeeded.
