# li-dm

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Get the recipient, an actual reason to reach out and the user's objective.
Use only supplied or verified relationships; never pretend the user read a post,
met someone or shares a connection. Write a concise note with character count,
a first message with one small ask, and at most two follow-ups if useful. Treat
200 characters as a conservative drafting budget, not a guaranteed platform limit;
verify current limits if asked. Suggested dates are advisory, never scheduled.
Stop after a decline or opt-out; omit follow-ups when there is nothing useful to
add. Apply li-fact-check and li-human. Return labelled drafts and manual next steps.
No credentials, automated connections or messages, or invented daily safety limits.
