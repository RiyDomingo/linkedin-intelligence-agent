# li-carousel

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Use a carousel when sequence, comparison or a framework benefits from slides.
Otherwise recommend li-post. Write a readable cover, stakes, one idea per slide,
recap and one useful close. Choose slide count from substance, not a fixed rule.
Respect supplied branding and public evidence. Apply li-fact-check and li-human
to slide copy and accompanying post. Deliver numbered copy first. If the user
requests export and suitable PDF/presentation tools are available, create and
visually verify the artifact; otherwise deliver copy and disclose that no PDF
was built. Verify current upload constraints if needed. No upload automation.
