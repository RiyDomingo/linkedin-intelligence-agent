# li-plan

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Read recent work, audience timezone, history and available analytics. If needed,
ask about capacity, real events and goals together. Apply li-ideas for concrete
angles, li-history for overlap and li-audit logic for descriptive evidence.
Choose a sustainable cadence with the user; mix proof, opinion, teaching, stories
and offers when actual material supports them. Do not assert universal best hours
or frequency. Label proposed timing as an experiment in the audience timezone.
Each slot: date, theme, angle, source material needed and optional hook reference.
Suggest engagement with supplied or verified people, not fabricated targets.
Return a calendar and manual next steps. Save `.linkedin-agent/plan.md` only if
requested, using an explicit path and preserving existing plans. No scheduling.
