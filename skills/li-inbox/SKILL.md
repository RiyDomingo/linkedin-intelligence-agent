# li-inbox

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Read pasted messages/screenshots only. Count LEAD, RECRUITER, PEER, ASK and
LIKELY SPAM with concise reasons and uncertainty. Sequence-like wording is a
clue, not proof of automation or fraud. Prioritize real questions; ask for missing
role/compensation details where relevant. Give warm declines without promises the
user did not make. Draft only worthwhile responses through li-fact-check/li-human.
Archive, reply and ignore are manual recommendations; never operate the inbox.
Do not persist private third-party messages into public content history.
