# li-audit

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Read user exports or local history and analytics. Map column definitions first.
Compute engagement rate = (reactions + comments + reposts) / impressions when all
inputs exist and denominator is positive; comment ratio = comments / reactions;
reach multiple = impressions / follower count with the correct dated follower
count. Zero denominators are unavailable, not zero. Missing metrics remain missing.
Show working and sample sizes. Compare top/bottom posts by normalized metrics,
topic, angle, hook, format and length; avoid causal claims from observational data.
Use saves/sends only when provided and defined. No universal algorithm assertions.
Summarize evidence, uncertainty, recommendations and a few testable experiments.
Pass findings to li-plan/ideas logic. Keep confidential analytics out of public copy.

When available, use normalized analytics via [li-read](../li-read/SKILL.md) and
confirmed relationship/comment context. Distinguish raw engagement, meaningful
comments, relevant-person engagement, opportunities, saves and strategic importance.
Report these only when actually supplied or supported by the discussion. Separate
observations from hypotheses; sparse counts do not establish audience/lead quality.
