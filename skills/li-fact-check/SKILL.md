# li-fact-check

Read [the shared context and approval contract](../li-context/references/context-contract.md) first.

Read [the claim gate](references/claim-gate.md). Split the draft into substantive
claims including hooks, comparisons, implied efficacy and quoted speech. Match
against relevant public bio, claims and metrics registers. Report claim ID or safe
excerpt, classification, evidence, permission, qualification and proposed action.
Use li-research only for external claims that need verification; research cannot
establish the user's private experience or override an NDA. Fail closed on conflicts,
unknown public permission or missing support: remove, qualify or retain placeholders.
Return a revised draft and unresolved blockers. Recheck after editing. A human must
still review; this reasoning workflow is not a deterministic truth oracle.

Request authoritative support for exact public claims; community sentiment cannot establish factual efficacy.
Delegate that public information need to [li-research](../li-research/SKILL.md),
using the shared contract and preserving evidence IDs.
