# Claim gate

| Classification | Meaning | Draft action |
| --- | --- | --- |
| VERIFIED | Exact statement matches checked evidence, scoped and dated | Use only if publicly permitted |
| USER-PROVIDED | User attests it; not independently checked | Preserve attribution/scope, establish permission |
| SOURCE-SUPPORTED | Opened external source supports exact statement | Cite source, scope and date; no exaggerated inference |
| NEEDS VERIFICATION | Plausible but unresolved, stale, conflicting or permission unknown | Placeholder, research or ask |
| OPINION | Clearly subjective judgment | Keep it visibly subjective; inspect factual premises |
| CONFIDENTIAL / DO NOT PUBLISH | Restricted even if true | Remove; do not repeat the secret in review notes |
| UNSUPPORTED | No supporting basis or contradicted | Remove or replace with labelled missing information |

Truth and publication permission are separate columns. Unknown permission blocks
use of personal/client facts. A public source does not authorize disclosure of
private relationships. Resolve contradictory records conservatively; a recent
user instruction can amend permission but cannot create independent verification.

Inspect explicit and implied numbers, customers, partnerships, results, dates,
credentials, quotations, comparison baselines, medical/product efficacy and causal
claims. Do not invent any. Match metric unit, denominator, period, definition and
qualification; avoid presenting a pilot observation as general efficacy. Verify
quotation wording and attribution. A source supporting correlation does not prove
causation. Never upgrade USER-PROVIDED to VERIFIED silently.

Example: source says “tested in a pilot” → cannot claim “clinically proven”.
Example: a source's revenue figure → cannot become “we earned that revenue”.
Example: a real but confidential customer → omit identity and identifying details.
Example: missing time-saving figure → `{{measured time saving}}`, not a guessed %.

Return a compact claim ledger beside the draft, not inside copy-ready text. Sources
should directly support the associated claim. Label unresolved content DRAFT —
NEEDS VERIFICATION and list what would unblock it. No clean style result bypasses
this gate. This is agent reasoning backed by evidence, not an automatic classifier.
