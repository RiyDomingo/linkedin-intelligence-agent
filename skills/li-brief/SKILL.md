# li-brief

Read [the shared contract](../li-context/references/context-contract.md) first.

1. Apply [li-read](../li-read/SKILL.md). Inspect status, refresh legitimate available
   account reads through the restricted gateway when needed; identify cache/import
   alternatives explicitly on failure, without claiming live success. Report gaps and dates; don't claim to see a feed
   or inbox that is unavailable. Review only relevant items, not the whole network.
2. Run the sibling li-read `scripts/intelligence.py --root <data-root> brief` for
   supported candidates, relationship obligations, freshness and transparent reasons.
   Read [attention guidance](references/attention.md). Scores are inferred ordering
   aids, not measured opportunity probabilities. Review thread context and facts.
3. Check publication/comment history and [li-ideas](../li-ideas/SKILL.md) for genuinely
   fresh content opportunities. Consider real recent work and current evidence even
   if a numeric heuristic did not select it. Use research only when it adds value.
4. Return 0–5 material actions, most important first. Each: person/item link or ID,
   why it matters now, relationship/prior interaction context, evidence, recommended
   manual action and a draft when useful. Only include useful sections. Explain
   stale/unknown sources rather than generating urgency or activity to fill space.
5. Draft selected replies/comments/posts through their existing skills. CLI draft
   placeholders are not final copy; resolve only from actual public evidence. Apply
   voice, claim gate and quality review. Private context never enters web queries.
   “NO RESPONSE NEEDED” and “nothing material found in available data” are valid.
6. End with human review and manual action. No autonomous write-side path exists.
   Save a local brief only when requested; do not schedule monitoring implicitly.

Inspect research_signals alongside reader coverage and relationship context; request only missing relevant developments or discussions.
Delegate that public information need to [li-research](../li-research/SKILL.md),
using the shared contract and preserving evidence IDs.
