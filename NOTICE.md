# LinkedIn Intelligence Agent attribution

Based on [linkedin-agent-skill](https://github.com/Jakeschincariol/linkedin-agent-skill)
by Jake Schincariol, copyright 2026, MIT licensed. The original LICENSE is retained
unchanged. Upstream supplied the eleven workflow concepts, hook library, profile
rubric, vocabulary/structure rules and deterministic humanizer foundation.

publication memory, factuality/research/idea workflows, safer Unicode handling,
observable style diagnostics, normalized read snapshots, selective daily/weekly briefs,
relationship context, installation helpers, tests and migration documentation.

LinkedIn standards or experimentally established performance guarantees.
